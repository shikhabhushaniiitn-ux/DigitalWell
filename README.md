
# DigitalWell – Digital Wellness Resource Hub

## Project Overview

DigitalWell is a student-focused digital wellness resource
hub designed to help college students discover, compare,
and use practical digital wellness resources.

## Objectives

- Help students manage screen time.
- Discover focus and productivity tools.
- Understand notification management.
- Develop healthier bedtime routines.
- Learn about privacy and digital safety.
- Compare free, paid, and open-source resources.

## Technology Stack

- Python
- Streamlit
- Pandas
- Pytest
- Git and GitHub

## Project Status

Initial environment setup and repository baseline.

## Disclaimer

This is an educational project and is not a medical,
clinical, or diagnostic platform.
