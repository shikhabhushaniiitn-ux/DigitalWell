## Verification limits

- Accessibility conformance was not independently audited for any provider. Entries say “Not stated in reviewed source” where appropriate.
- Dynamic pricing is omitted unless the reviewed source explicitly supports a plan description; verify current prices on the provider site.
- Privacy notes describe only reviewed statements and permissions. They are not a security audit or guarantee.
- Firefox ETP source reviewed here describes desktop behavior; mobile details are not asserted in the catalogue.
- URLs are validated syntactically by the loader. This check does not test that a live page is reachable.
